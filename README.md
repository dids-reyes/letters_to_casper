# Letters to Casper

A place to share heartfelt letters and thoughts anonymously.

Visit [letterstocasper.com](https://letterstocasper.com).

## Local development

Install the dependencies:

```sh
npm install --legacy-peer-deps
```

Create a `.env` file with the configuration required for your environment, then start the app:

```sh
npm start
```

## Available commands

```sh
npm test
npm run build
```
